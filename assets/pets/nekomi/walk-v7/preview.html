帧检查

六帧顺序

接触 A → 支撑 A → B 摆腿通过 → 接触 B → 支撑 B → A 摆腿通过 → 首帧。

A / near = 近侧；B / far = 远侧。这里不使用人体左、右称谓。

足落点

● 近侧 A● 远侧 B＋ 锚点

实心圆为接触脚，空心圆为摆动脚；heel / toe 为人工观测的原图坐标。橙、蓝线分别为近、远脚道投影线，表示同一地面的透视深度，不是两个物理地面高度。紫十字为共享锚点，不等于脚底线。

点击图像可读取原图坐标，便于人工核对；不会写入脚点文件。

检查范围

  • 两脚与手臂反相，膝、踝和脚尖方向一致。
  • 落脚接触与抬脚高度明确，无漂浮鞋、交叉腿。
  • 身份、比例、头饰、裙花与细尾保持连续。
  • 末帧回首帧是否突跳；位移时支撑脚是否明显滑动。
  • 深浅背景下的透明边缘与完整轮廓。

这是绘制素材预览。没有淡入、逐帧轮廓归一化、生成补间或桌宠运行时接线。

显示高度为整个画布高度。原始 PNG 字节保持不变，预览只统一缩放画布并可选整体平移。技术测量与当前 SHA 对应的人工视觉证据分别记录；未审核的素材不会显示已验收。
