# Nekomi 高清姿势素材 v1

这套素材包含 12 张独立透明 PNG：站立、招手、庆祝、警觉、困倦、害羞、亲昵、伸懒腰、眨眼、开心、鞠躬和抱尾巴。每张原生画布为 1024 × 1536，面向约 1200 像素角色高度的显示需求。

全部由内置 image_gen 工具生成，并按原始字节保存；未使用代码放大、补画、抠图或修整像素。完整提示词位于 prompts/，来源和文件指纹记录在 manifest.json、generation-*.json 与 image-analysis.json。

## 查看

解压后直接打开 preview.html。可切换深色、浅色和棋盘背景；点击姿势进入单张大图及手部、脚部、腰线局部查看。PNG 本身保留透明度，页面背景不会写入原图。

## 使用范围

本次交付是高清原图素材包。当前桌面宠物仍使用原来的 v5 图集，本次没有更改渲染器或运行中的皮肤。后续接入高清显示时，需要逐姿势按需加载、统一角色比例和脚底基准，并调整窗口/缩放上限；不能把十二张大图直接当作旧图集导入。

检查范围包括原生尺寸、透明通道、可见轮廓留白、深浅背景、放大手部、脚尖方向、腰线和头饰。手部允许透视及自然遮挡；这是 Q 版插画视觉复核，不代表写实人体解剖认证或动作过渡验收。
