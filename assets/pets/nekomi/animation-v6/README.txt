小柚 v6 动画制作素材包

双击 preview.html 即可离线查看，不需要启动服务器。
12 个动作各有 base / enter / accent 三张独立透明 PNG；idle 另有半闭眼和闭眼。
它们是已有主姿势内部的有限局部关键帧，不含从待机到举手、抱臂等完整过渡。
sleep 表现闭眼与尾巴微动，未提供胸腹呼吸形变或 24 fps 密集中间帧。
base 为上一版已验收 v5 原图的逐字节复制，新图也保持生成器原始字节。
所有帧使用同一 1024×1536 画布；每个动作共享比例、锚点、位置。
预览是明确的逐帧切换，没有 crossfade、插值或逐帧轮廓归一化。
播放节奏是交接参数，可在后续动画制作中调整。它不是密集连续中间帧。

layers/ 中提供分离的栅格图层与 pivot / z-order / placement 元数据。
图层允许用矩阵把生成器的原生画布装配到目标画布；这只影响显示，不改写 PNG。
只有组合视觉复查通过后才可视为拆分素材完成；数值尺寸通过不能证明装配正确。
该包不是可直接导入的完成 PSD，也不是已绑定参数、网格、物理和动作的 Live2D 工程或运行时模型文件。
本包没有修改 src、运行时 manifest，也没有替换已运行的桌宠。
行走步态不属于本次 12 个原有动作范围。

animation-manifest.json 记录当前帧、SHA、共享锚点、时长与播放序列。
validation-report.json 和 visual-review.json 记录技术检查与当前文件的逐帧视觉复查。
generation-*.json / prompts/ 保留生成来源；旧版及失败历史在工作区继续保留。
