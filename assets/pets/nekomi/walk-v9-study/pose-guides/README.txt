03 远腿经过姿势参考

用途：按候选角色像素约束构建的绘图参考，帮助校正近远腿的连接、长度与遮挡。
不是 v9 米制工程模型重映射，不定义角色 Q 版比例，不是人物图或人物通过证据。
SVG 完全由代码原生矢量图形构成；PNG 只由该 SVG 渲染，未嵌入、读取、修改或重采样任何人物 PNG。

固定画幅 1024×1536，白底，地面 y = 1447。
近腿（teal，后绘前层）：hip (590,790), knee (630,1070), ankle (590,1340)。
远腿（gray，先绘后层）：hip (590,790), knee (705,1048), ankle (587,1294)。
近脚 heel (541,1447), toe (753,1447)。
远脚 heel (538,1401), toe (750,1401)。
远脚相对近脚只偏移 (-3,-46)，不能为了显示完整鞋子而额外向左移。
近层允许遮挡远层；灰色虚线只是被遮挡关节的说明连接，不表示远腿体块位于近腿前面。
粗胶囊及多边形仅是工程图形，不是建议照抄的人物轮廓或服饰。

严格欧氏长度：
近髋—膝：sqrt(40²+280²) = 282.842712474619 px。
近膝—踝：sqrt(40²+270²) = 272.94688127912366 px。
远髋—膝：sqrt(115²+258²) = 282.46946737656447 px。
远膝—踝：sqrt(118²+246²) = 272.8369476445593 px。
对应上段长度差 0.37324509805455364 px；下段长度差 0.10993363456435645 px。
指定的整数坐标有小幅段长差；本参考保留这些输入点，不以静默改变点位伪装完全等长。
两脚 heel—toe = 212 px。
两脚 ankle—heel 偏移 (-49,107)，ankle—toe 偏移 (163,107)，几何完全相同。

本单帧脚底均为水平，只用于此经过阶段的姿态约束；不能证明脚滚、地面接触连续性或完整步态。
