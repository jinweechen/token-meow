# Token 喵

一款 Windows 桌宠应用，用猫娘「小柚」陪伴工作，同时查看本机 Codex 用量。

## 功能

- Token 用量统计与趋势
- 订阅额度查看、使用计划与条件预测
- 会话、工具记录与完成提醒
- 桌宠动画、拖动缩放与免打扰
- 桌宠体验扩展开发：本地皮肤动作预览、轻互动和受限移动
- 本地账本、隐私模式与 CSV 导出
- Codex、Claude Code、Gemini CLI 来源登记与逐来源账户概览
- 周期模板、自由日程及手动 requests/credits 预算
- 条件多模型拟合、滑动释放场景与本地观察摘要

官方额度、已记录用量、用户目标与条件估算分别显示。厂商证明不足时不自动换算会员 Token 容量，仍可从现在创建本机使用计划。

桌宠扩展保留原生开发开关，真实走动验收暂缓。

本轮扩展新增原生文件拖放确认和离线 VRM 1.0 角色导入、预览与切换，复用 Tauri、Three.js 与官方 three-vrm。完整操作系统拖放与 WebView2 渲染尚待实机验收。

订阅页提供周期与自由日程、条件拟合和滑动窗口，用量总览提供每日摘要、时间线与模型条件样本。本地模板和数值计算不额外调用模型，手动实验不换算为官方额度或通知资格。

## 开发

技术栈：React · TypeScript · Tauri · Rust · SQLite

使用 Node.js 24 和 pnpm 11.25.0 启动界面预览：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

访问 `http://127.0.0.1:1420`。
