# Token 喵

一款 Windows 桌宠应用，用猫娘「小柚」陪伴工作，同时查看本机 Codex 用量。

## 功能

- Token 用量统计与趋势
- 会话、工具记录与完成提醒
- 桌宠动画、拖动缩放与免打扰
- 本地账本、隐私模式与 CSV 导出

## 开发

技术栈：React · TypeScript · Tauri · Rust · SQLite

使用 Node.js 24 和 pnpm 11.25.0 启动界面预览：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

访问 `http://127.0.0.1:1420`。
