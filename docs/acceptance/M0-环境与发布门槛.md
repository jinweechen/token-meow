## 冻结测量口径

| 指标 | 门槛 | 测量条件 |
| --- | --- | --- |
| 增量可见延迟 | 完整行可读后 P95 ≤ 5 秒 | 固定脱敏 JSONL，导入结束后追加至少 20 个事件，包含采集到前端查询时间 |

| 常驻私有内存 | ≤ 350 MiB | 面板关闭，导入结束，含 WebView2 与自有子进程；10分钟采样均值及最大值均记录 |
| 导入私有内存峰值 | ≤ 600 MiB | 首次最近30天本机 JSONL 导入，含 WebView2 与自有子进程；记录文件数/字节数 |

不因后续结果反向放宽门槛。单次截图、进程启动成功和核心查询延迟均不能替代以上指标。

## 数据与能力冻结

- 唯一事实优先级：顶层原生 `token_usage_record.payload.usage`；累计通知与压缩快照不重复计入。
- 原生候选身份：稳定来源实例 + `payload.thread_id` + `response_id`。文件拥有者使用第一个 `session_meta`；继承元数据不覆盖拥有者。
- `task_complete` 若没有明确结果字段，仅表示“已结束，结果未知”；不推定业务完成或测试通过。
- 时间按 UTC 保存、Asia/Shanghai 展示与按日归组；输入、输出、缓存、推理为包含关系。
- 账户快照独立于本机账本；不把当前账户身份回填给历史用量。
- 官方桥接使用自有隐藏 stdio 子进程，只允许 initialize / initialized / account/read（refreshToken=false）/ account/rateLimits/read / account/usage/read；不发起推理，不登录，不恢复线程，不改 Codex 配置。
- 当前没有公开稳定的日志字段规范。日志适配以本机0.147.0字段探测及固定脱敏样本为准，遇到未知格式降级并显示问题。

## 验收状态规则

按“实现 / 自动验证 / 本机原生验证 / 发布门槛”分别留存。未验证的多屏、DPI、睡眠、聊天定位、升级卸载不得写为通过。签名缺失只限制分发状态，不能抵消性能门槛。

原方案 M0 的 Windows 透明窗口、穿透恢复与聊天定位探针将随最小壳运行验证；在该探针完成前，前端与核心实现属于并行开发工作，不代表 M0 桌面门槛已通过。

## 已核对的主来源

- [Codex App Server](https://learn.chatgpt.com/docs/app-server)：握手、账户读取及限额字段。额度只显示窗口百分比，不换算剩余token。
- [Tauri 系统托盘](https://v2.tauri.app/learn/system-tray/)与[配置](https://v2.tauri.app/reference/config/)：Windows透明窗、窗口关闭与托盘。

正式验收记录将引用运行输出和固定输入，不通过重复运行既有账户查询来替代集成验证。

## 2026-10-15 只读桥接补充验证

实现新增的 `thread/list` 已纳入只读桥接白名单，固定 `useStateDbOnly=true`，显式覆盖工具已公布的来源类型，分别读取活动与归档分页；不通过线程加载或正文补全获得目录。重复游标、页数与条数上限触发明确失败，不声明完整覆盖。这是对上述初始白名单的补充，不回写原有验收结果。

本机直接编译生产 `account_bridge.rs` 的 audit example 已读取账户额度及 77 个账户日趋势桶，并完整遍历 555 条目录元数据，其中归档59条；输出没有 preview、turns、messages、body 或运行状态字段。缺少可验证账户域时仍保留未知，不将当前登录身份回填历史。退出后 Codex 进程数由9回到9，原有进程均在，未遗留新Codex进程；源config/auth摘要未变化。

证据为 `output/live-account-bridge-20261015.json` 与 `output/live-account-process-20261015.json`，可分发范围摘要见[桥接验收记录](live-account-bridge-2026-10-15.json)。这是实时只读桥接与进程回收证据，不代表原生产品界面、认证切换实机故障或发布验收完成。
