# 本地 PNG 皮肤目录包 v1

2026-10-18：本地扩展开发接口。Windows 新版安装包与原生交互验收尚未完成；本页不表示发布通过。

普通启动不开放这三项 P1 功能。开发验收时仅在专用进程环境设置 `TOKEN_MEOW_P1_DEVELOPMENT=1`，再启动新构建的 App；主界面从原生能力接口读取该开关，原生写入、帧读取、透明命中和临时交互命令同样检查开关。它不是验收通过标记，不修改系统环境变量，也不授予素材包原生能力。

在“偏好设置 → 桌面伙伴 → 本地 PNG 皮肤”选择目录。目录仅包含 `manifest.json` 和 `frames/` 下声明的 PNG。导入保存独立副本并检查全部图片，预览成功后再点击“使用此皮肤”。取消、校验失败或预览失败不会切换当前角色。未使用的包可以移除；当前包先切回内置角色。许可和署名是包作者声明，导入器不证明素材权利。

请选择应用存储目录以外的素材源目录；应用内部已安装的副本通过列表预览和选择，无需再次导入。

清单使用 UTF-8 JSON，拒绝未知字段、额外文件、路径跳转、链接与 Windows reparse point。固定字段如下：

| 字段 | 值或约束 |
| --- | --- |
| `schema_version` | `1` |
| `renderer_kind` | `local-png-clips` |
| `name` / `author` / `source` / `license` / `attribution` | 非空文字，UTF-8 上限依次为 128 / 256 / 1024 / 256 / 2048 字节；无控制或方向覆盖字符 |
| `bounds_alpha_threshold` | `127`，轮廓范围使用 alpha 大于 127 的像素 |
| `static_pose` | `idle` |
| `frames` | 最多 64 帧，每帧原生 RGBA PNG、1024×1536、最多 4 MiB，完整包编码数据最多 128 MiB |
| `clips` | 必须包含 `idle`、`active`、`complete`、`alert`、`sleep`；仅允许现有 13 个逻辑姿势 |

帧条目包含 `id`、`path`、`width`、`height`、`bytes`、`sha256`、`bounds`。标识只允许小写 ASCII、数字、连字符或下划线，最长 64 字符，并拒绝 Windows 保留设备名。路径固定为 `frames/<id>.png`；SHA-256 为原 PNG 字节摘要；`bounds` 为 `[left,top,right,bottom]`，右、下边界不含在范围内。实际解码像素、透明边角及声明轮廓均需匹配。

片段包含 `id`、`fallback`、`canvas:[1024,1536]`、`sharedTransform:{scale:1,anchor:[512,1490],translate:[0,0]}`、`loop`、可选 `loopRange:{start,end}` 与 `sequence`。每个序列条目为 `{frame,durationMs,segment?}`，单步 16–10000 ms、每段最多 64 步和 12 个不同解码帧、总时长最多 60 秒。`loopRange` 只用于循环片段，右端索引不含在范围内。`idle` 必须循环，`complete` 不循环。所有帧必须被至少一个片段引用。

扩展姿势为 `shy`、`affection`、`stretch`、`wink`、`happy`、`bow`、`hug-tail`、`walk`；缺少时使用 `idle`。`walk` 仅显示画面，不授予移动能力。皮肤不声明原生能力，不包含脚本、SDK、外部 URL 读取或模型调用，也不能改变账本和任务结果。

存储位于应用数据目录的 `local-pet-skins-v1`，最多 8 包，损坏包也占名额。包标识由清单原始字节的 SHA-256 分配。选择记录独立保存，不写入用量事实。坏清单或选择记录显示诊断并回退内置角色；原有坏记录保留，显式操作才修改或移除。运行时读图只接收包标识和帧标识，不接收任意文件路径。

透明区域命中默认关闭，使用最多 128×192 格的保守 alpha 区域及原生边缘余量，并保留文字和按钮区域。帧切换先清除旧区域，原生确认后才呈现；检测到布局变化后使旧区域失效并重新计算。掩码一秒未续期恢复完整矩形。它是保守轮廓命中，不等同严格逐像素命中。

临时交互通过设置、托盘或 `Ctrl+Alt+I` 开启 15 秒，由原生单调时钟到期恢复当前整体穿透偏好。关闭弹层、隐藏、换来源或重置也会结束。`Ctrl+Alt+M` 仍为永久恢复入口。多 DPI、跨进程透明区点击、焦点、睡眠恢复与资源回收仍须使用新版 Windows App 验收。
