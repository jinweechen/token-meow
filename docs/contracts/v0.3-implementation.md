# v0.3 实施契约补充

更新日期：2026-10-16。适用开发方案 v0.3；本文件冻结实现选择，不替代开发方案或验收结果。

第7、8节保留C17、C18各自的历史版本边界。当前主源码使用schema6，后续增量以第9至13节为准；封存候选中的契约副本与验收摘要不随主源码修订。构建、固定样本、浏览器与Windows实机证据各自保持原范围。

## 1 来源、计量与身份

首版仅注册 Codex 内置适配器。通用层接收标准事件；第二语义仅用于人工可核对的合成契约测试，不提供可用的 Claude/Gemini 入口。

每条事实具备稳定来源、通道、原生唯一域、物理定位、事件/采集时间、解析器及语义版本。物理记录身份包含文件身份，不能由相同字节偏移推断相同事件。事件业务身份不包含后补模型、账户或显示名称。

可选指标分有效、未提供、语义未知、异常四种状态。有效的 0 保留。派生值仅使用满足包含关系的有效子集；汇总同时报告该子集覆盖率。原生计数保留允许的计数字段，用规范化版本解释变换，不保留正文。

同域同身份出现不同计量载荷时，保留原事实与冲突证据，将**整个争议响应**排除于可信总量、响应次数及预算计量；显示被排除的响应数量和原因，不选较小值或第一条作为可信值。既有提醒不删除或再发，重算只更新依据。未来解决冲突需持久化具体证据、选择与修订记录，并事务重建受影响聚合。

跨来源相同短 ID 不自动构成冲突。明确独立身份域分别计量；有证明的复制关系合并；无法证明的重叠范围单列并排除于无重复总计。

Codex 当前顶层用量适配器不启用流式用量修改语义，同身份异计量按冲突处理。通用修订接口必须由适配器显式声明，携带单调序号与 partial/final 状态；旧序号丢弃，final 不得降回 partial，相同序号异载荷进入冲突，未验证修订能力的来源不得更新旧计量。任一更新和汇总重算在同一事务完成。

响应、聚合、额度、上下文、计时为不同类型；聚合/快照不能制造响应次数。缺少回合身份时仍可保存有效响应模型，不伪造回合。未知账户不按当前登录回填。

会话目录桥接按页只读元数据，当前本地单次合并安全上限为10,000条。超过上限在首笔写入前明确拒绝，保留原目录快照和旧成功水位，不报告完整覆盖；桥接可分页读取不等于本地支持100,000条目录导入。来源健康按每个启用来源汇总，不被页面日期或模型筛选裁剪；未检查来源保持未知。

历史补导和实时尾读分别保存可恢复游标。暂停或取消只停止历史游标，新增文件和已有文件的新尾部仍按实时通道采集；取消状态在重启后保留，必须显式补导才重新安排历史。共享位置只解析一次，真正历史缺口使用双游标；同一物理文件的待处理数量只计一次。无可验证累计基线时保持未知，不通过减去零制造用量。

## 2 提醒身份与回放

- 完成提醒身份：规则版本 + 来源实例 + 原生根回合身份。未知结果后补明确结果更新同一条，动画播放回执与收件箱已读状态独立。
- 预算提醒身份：预算规则版本 + 来源范围 + 目标范围 + Asia/Shanghai 周期 + 阈值档位。跨阈值的某条响应不是提醒身份；后续响应、重投和重算不再发同档提醒。规则阈值变更产生新规则版本，但保存时不回弹历史通知。
- 首次历史导入与重启补读只进入历史收件箱，不主动弹窗/播放短提示。免打扰期间保留事实并推进提示水位，恢复不补播。隐藏角色只停止角色渲染与动画短提示，仍可按独立提醒设置发送系统视觉通知；隐藏不等于免打扰。锁屏、屏幕关闭或挂起期间抑制主动提醒，恢复不补发。
- 提示队列最多 8 条，短提示有效期 10 秒，完成动作 2 秒，普通动作冷却 3 秒。失败/中断可打断普通完成；用户拖动、菜单、关闭始终立即响应。状态事实不因动画结束改变。

## 3 设置与桌面生命周期

Core.settings 是唯一持久设置权威。前端设置通过有限命令写入，桌面层投影窗口效果。默认 muted=true、doNotDisturb=false、reducedMotion=false、startAtLogin=false、clickThrough=false、alwaysOnTop=true、scale=1。操作系统减少动画也应生效。

旧 pet-options.json 如存在只迁移一次；Core 内已有明确值优先，未定义项才使用旧值，其余采用当前默认值。迁移有版本且保留旧文件，不在运行时维护两套可冲突设置。

窗口位置作为桌面设置保存显示器、工作区内逻辑坐标与缩放。拖动结束后才校验可见性；屏幕变化、DPI 和睡眠恢复重新校验。自动变化使用不激活方式，主面板仅在用户明确操作时激活。快捷键注册失败进入数据健康，托盘找回必须可用。

退出流程：停止安排新扫描/刷新，通知 worker 取消，当前完整采集批次提交或回滚，最长等待 5 秒。到时结束本程序拥有的账户管道/进程，未提交事务由 SQLite 回滚；不强制提交半批次。恢复时从最后提交游标继续。Windows 自有桥接使用 KILL_ON_JOB_CLOSE 作异常退出保障，不触及现有 Codex 进程。

账户与会话目录共用唯一只读桥接的启动准入和失败退避，目录定时读取不能绕过账户路径的退避重新启动进程。初始化、EOF、超时、取消或资源故障不能制造成功快照；退避期间未实际读取不更新采集或尝试时间。额度读取失败时本次账户读取整体失败；只有账户日趋势的“不支持方法”（-32601）或普通服务端拒绝可局部降级，保留本次有效额度、令日趋势为未提供并显示警告。日趋势发生传输断开、超时、取消或资源故障时仍按整体失败处理，有旧快照则标为 stale，没有旧快照则为 unavailable，不将缺失值补零或推断为未登录。

Windows 可选官方桥接以挂起方式创建，在任何桥接代码执行前绑定专属 Job；仅继承受控标准输入、输出和错误句柄，自有后代不能 break away。该 Job 设置 96 MiB 提交内存通知预警和 128 MiB job-wide 提交内存硬限制。硬限制拒绝超预算提交，不等于自动终止，也不保证一定观测到硬限事件；只有实际硬限通知才能记为硬限事件，普通 EOF 或超时不能冒称触限。观察到预警、硬限事件或运行中预算监视故障时，锁存资源熔断并请求终止整个自有桥接 Job，释放管道和监视线程。本次应用运行中，资源熔断不随周期刷新、清理缓存或切换来源复位，只有用户在账户额度处明确手动刷新才允许解除并重新尝试；健康 transport 和已知单项能力结果不因手动刷新无故重建。预算始终有效。本应用不直接读写 Codex 凭据或状态数据库，不以凭据文件缺失推断未登录，也不调用登录或配置写入方法；官方 app-server 启动可能自行维护状态库，不承诺整个 CODEX_HOME 零写入，不通过关闭官方 SQLite 维护规避资源验收。128 MiB 仅为桥接子预算，不能替代整个应用及全部自有子进程的 350/600 MiB 验收门槛。

## 4 原创内置角色与资源

当前源码默认采用v6的38张1024×1536透明PNG关键帧，清单为`assets/pets/nekomi/manifest-animation-v6.json`，声明`schema_version=2`、`renderer_kind=builtin-animation-clips`。帧声明路径、尺寸、字节数、SHA-256和轮廓边界；12个动作声明共享画布、锚点、序列与时长。保留原图字节，同一动作不逐帧按轮廓重新缩放，也不渐变叠图；使用单调时钟按截止时间选择当前帧，迟到回调不补播错过的帧。待机包含75/100/75毫秒眨眼。原图、提示词与生成记录位于`animation-v6/`，12张基础帧与v5原图逐字节相同。28张分层PNG仅作后续制作交接，不进入当前运行时，不声明已绑定Live2D或具有行走步态。

五类语义动作对应待机、招手、庆祝、警觉和困倦；七类闲置／轻触姿态对应害羞、亲昵、伸懒腰、眨眼、开心、鞠躬和抱尾巴。静态与减少动画使用新待机图，免打扰保留静态困倦姿态。闲置动作不得制造完成结果或覆盖真实活动和提醒。旧图集、旧SVG角色及其加载模块已从主源码删除；历史候选及验收记录仍只属于原版本。加载失败显示独立的简洁占位和状态文字，皮肤不控制事实结果。

项目本体开源许可尚未由用户选定，不使用包元数据替用户授权。内置原创资源以 LicenseRef-Project-Owned 记录，分发依据为本项目原创并随本应用分发；第三方独立复用未另行授权。依赖自身许可证与本项目许可分开列出。

清理本应用数据时，同时使自有账户/目录缓存失效并清除桥接观察，保留共同启动退避与资源熔断；切换来源也不能绕过这些保护。旧在途响应按来源和清理代次拒绝发布，目录旧成功时间与数量不能串到其他来源或清理代次。保留来源选择和同一取消句柄，不读取或删除Codex凭据与日志。满足准入条件后的真正新读取可重新产生账户快照，不能将旧RAM快照重新附回并冒充新采集。

v6运行包固定38帧、12动作，实际原图编码总量73,937,625字节；单帧不超过4MiB，整包上限80MiB。每个WebView只有一个片段加载owner，仅加载当前片段的3张或5张独立帧；受控URL与正在解码的图片合计最多5槽，逻辑RGBA预算为30MiB。只保留一个执行请求与一个最新候选，不预载全部38帧。读取长度、摘要、PNG头、尺寸和透明角均校验；原稿有经hash绑定的1/255角点残留，v6允许四角alpha整数0..1，不改写原图。解码串行，临时bitmap及时关闭，片段切换/取消/失败清理旧URL，迟到结果不能复活。减少动画或免打扰只读取一张基础帧；隐藏、系统暂停或组件销毁取消加载和计时，释放当前片段资源。非BFCache的pagehide和开发热替换终止owner。仅读取同源内置URL，拒绝重定向；该逻辑槽位预算不能替代浏览器/WebView及全部自有进程的实际内存、CPU或M4验收。历史C24-HD的12帧/12MiB合同和证据仍仅属于历史候选。

2026-10-15 用户报告菜单点击桌面不能关闭。常驻宠物保持不可激活；用户主动打开菜单或小卡时取得临时焦点，失焦/点击窗外/按Esc/操作结束/隐藏/销毁均释放该状态，不持久修改宠物偏好。原生失焦事件和异步请求使用单调序号，旧事件不能关闭新打开的弹层；返回原窗口只在当前前台仍为宠物时进行，用户已点击其他窗口时不再抢回。

动画与采集时钟独立。同状态更新不重启动画；动画片段不能延长业务动作许可。文档可见与原生视图可见分别记录，二者都允许时才加载和播放，原生可见消息不能覆盖document.hidden。加载带代次，过期结果不重开隐藏窗；组件销毁释放独有计时器/订阅，隐藏暂停释放当前片段但保留可复用owner，窗口最终销毁释放全部对象URL。内置角色重载/隐藏恢复循环固定为30次，恢复后活动计时器和订阅回到基线；私有内存测量在10秒稳定后采样60秒，与首轮同条件相比增长不超过20MiB，仍需满足既有350/600MiB总门槛；这些Native门槛仍待实测。

## 5 工作联动与关心语（用户新增范围）

2026-10-15 用户要求加入工作联动及关心语，并选择温柔与卖萌两种风格交替。新增设置仍由Core唯一持久化：workCareEnabled默认true，careTone默认mixed（gentle/playful/mixed），careIntervalMinutes默认25（25/45/60）。无效类型或候选值拒绝整次保存；关心语不调用模型、不发送声音或新增系统通知。

文字气泡配合现有工作姿态：实际观察到的回合开始、明确正常结束、失败/中断、结果未知、本地软预算以及持续活动关心。只消费已有明确事实和符合原提示水位/新鲜度的事件，不从历史工具退出码推断回合成败；结果未知仍明确待确认。摸摸可收到本地回应，但不能覆盖高优先结果提示。静音只控制既有音频设置，关心语由独立开关控制；减少动画时仍可显示静态文字。

一次最多一个8秒气泡，不维护补播队列。自动提示有60秒冷却，高优先风险/结果可取代较低优先开始句；手动互动冷却3秒。mixed只在实际显示时推进语气轮次。首次真实快照只建立基线，历史、重启、来源变化、隐藏、锁屏、免打扰和菜单遮挡期间不弹出，恢复不补播；关闭关心语仍保留原有摸摸姿态及事实角标。

25/45/60分钟关心依据持续收到的新活动快照；观察间隔超过15秒或时钟回退即使基线失效，不能拿保留的旧活动状态宣称当前仍在工作。文案只说“回合仍在进行”，不宣称用户本人持续工作时长或健康状态。源/运行态改变仅重建观察基线，不重置交替语气。仅使用现有快照轮询与一个有限到期timeout，不新增常驻interval；隐藏/免打扰/销毁回收timeout与监听。气泡可关闭，可明确点击“打开主面板”，不伪称已定位到未实际打开的具体页面。文案不插入项目名、路径、会话标题或正文。

以上数值在实现前固定。功能或资源未验证不能将门槛改成已通过，也不以静态截图替代 Windows 交互与长期资源验收。

## 6 全局代理类型与关系证据

`Query.agentKind` 可省略，或为 `primary`、`subagent`、`unknown`；省略表示全部，其他值明确拒绝。统计、回合、工具、收件箱、旧格式估算和响应 CSV 使用同一条件；全局活动、逐源健康及软预算不随该筛选裁剪。会话页分类按钮与全局筛选共用查询状态，迟到回复受完整 Query 与代次约束。

主代理表示来源明确记录的用户线程，不证明用户亲自发起、没有子代理或属于主账户来源。当前正判仅接受已核对的 Codex `0.147.0` 中明确 `thread_source=user`；JSONL 使用 `cli_version` 和 snake_case 字段。目录使用 camelCase 字段，线程创建版本 `cliVersion` 不能证明 RPC 实现版本；当前没有独立验证的结构化 RPC 版本绑定，目录 `user` 因而保持未知。未知版本、缺失/null、普通 `source=cli/vscode`、`rootThreadId==id` 都不能自行证明主代理。依据见 [Codex 0.147.0 协议定义](https://github.com/openai/codex/blob/rust-v0.147.0/codex-rs/protocol/src/protocol.rs)。

明确父关系或合法子代理来源可提供子代理正证据。旧 v3 元数据中保留的非空父关系只作为既有关系断言；不伪造版本来源，不急切重写历史。后到元数据可以补齐占位记录；不同父关系、用户分类与子代理/内部来源矛盾、自指或畸形结构保持未知，不能被后续空值、重复值或最后写入覆盖。内部证据版本为 1，最多保留 2 个父候选、2 个分类标记和 8 个去重观察；不保存任意 feature/custom/other 文本、昵称、代理路径或指令。返回 DTO 去掉内部证据，只输出分类及原因。

`rootThreadId` 必须由完整、无冲突的父链到达有主代理正证据的终点；缺祖先、未知终点、循环或超过深度上限返回空。查询不改原始计量身份、计数、字节游标或已存 `rootTurnId`。同来源回合归属查询必须在完整来源与回合域中确认唯一线程，不能使用无序 `LIMIT 1` 作为证据；多线程歧义不生成新的完成提醒。唯一原生用量归属与元数据时间分开处理，纠正已有收件箱归属不能重建提醒身份或重放通知。

## 7 账本版本 4 与查询索引（C17 阶段）

版本 4 仅增加 `usage_source_turn_thread(source_id,turn_id,thread_id)` 索引，不改计量表字段或重新导入日志。已有低版本数据库升级前使用 `VACUUM INTO` 生成 UUID 命名的 `ledger-before-v4-*.sqlite3` 一致副本，包含已提交 WAL；备份失败直接停止升级。所有待执行的 001 至 004 DDL 置于同一个 IMMEDIATE 事务，任一步失败全部回滚；不以 `IF NOT EXISTS` 掩盖 v4 索引同名碰撞，不自动删除用户数据库对象。高于 4 的数据库在迁移与业务写入前拒绝。重复打开版本 4 不重复备份或建索引。

该段保留 C17 的版本边界。C18 的当前账本版本为 5，备份与拒绝边界按下节执行；C17 历史回执不改写成版本 5 的结果。

## 8 常驻宠物独立读取模型（C18）

常驻宠物使用独立 `PetPulse`，不接受主面板 Query，不调用完整 `snapshot/load/source_rows` 后再删字段。仅返回全局根回合活动与待确认计数、宠物设置、健康摘要、上海今日未读数、不含路径的来源与清理代次摘要，以及有界短提示批次。来源摘要覆盖当前主来源、全部来源的 id/root/enabled/runtime、运行实例、上海日期与清理水位；隐私模式、面板分类和日期筛选不能裁剪该语义。尚未收到确认读取时保持明确 loading；读取失败不把缺失计数补零，不更新旧值的观察时间。

小卡打开后才请求 `PetDetails`，关闭、隐藏或锁屏后停止详情读取。其请求绑定已接受 Pulse 的 runtimeEpoch/sourceScopeRevision/day；响应另带 asOf 与十进制字符串读取序号。序号表示成功读取顺序，不冒充事实修订版本。今日可信原生总量和有效配对缓存率保留 alias/excluded/未知计量规则；没有可信计量为 null。最近回合先按既有 completedAt/startedAt 与稳定次序选择，再取可空 TTFT，不能借用旧回合的非空值。账户仅投影已绑定主来源的缓存额度窗口及采集/过期依据，不启动 RPC，也不返回官方日趋势。完整 Snapshot 和面板合同保留。

账本版本 5 新增 `pet_inbox_feed`：AUTOINCREMENT 到达序号、唯一 inbox_id 及删除级联，不复制提醒内容。迁移回填既有身份，之后只有 inbox 的真正 INSERT 产生序号；同 ID 的结果修订、已读、动画确认、通知 claim 和归属纠正均不产生新到达。迁移 001—005 同一 IMMEDIATE 事务完成，已有低版本先生成 `ledger-before-v5-*.sqlite3` 一致备份，版本高于 5 在迁移和业务写入前拒绝。清空收件箱的删除与 inboxWatermark 写入同事务提交。留存或清理删除 feed 行，但不重置 sqlite_sequence 高水位。

提示游标包含运行实例、来源/清理代次、上海日期和精确十进制到达序号。首次、恢复基线或域变化时直接基线到本次持久高水位，返回空批次；这表示确认基线，不能由前端初始空对象替代。恢复较早备份时，旧域的合法较大序号也只建立新基线。有效游标处理 `(cursor, highWater]` 的新到达行并推进到 highWater；过期、未来、时间无效、其他日期、非本运行可播放和溢出行也推进，不因 ack 或结果修订重新露出旧尾。当前域序号超前、非法类型与非十进制值明确拒绝，不舍入成 JS Number。

一批最多 8 条符合资格且 age 在 0—10 秒的今日短提示，风险/未知/预算优先于普通完成，同档按原创建时间与稳定身份排序。溢出只丢弃这次短提示，丢弃数量分原因返回；原始收件箱事实与未读计数完整保留。该传输上限不宣称与旧全量队列无损等价。两个表现消费者共享同一不可变批次；游标推进或溢出不等于显示送达，仍仅在动画实际开始后持久化 ack。首次确认、隐藏/DND/来源变化、跨日、时间回退及超过 15 秒断流后的静默规则继续有效，不能补播历史或延长原时间的 TTL。

原生延迟、暖启动、完整导入、常驻 CPU/内存与渲染生命周期门槛保持不变。有界结果和逐行标量读取不等于恒定查询耗时，须以当前候选独立验证，不继承 C17 或私有原型的性能资格。

序号使用 SQLite 的 [AUTOINCREMENT](https://www.sqlite.org/autoinc.html) 防止删除后重用，接受其额外写入开销，不要求连续无缺号；高水位来自 sqlite_sequence。稳定身份修订沿用 [UPSERT](https://www.sqlite.org/lang_upsert.html)，feed 使用实际 INSERT 触发器；删行使用已开启外键的 [ON DELETE CASCADE](https://www.sqlite.org/foreignkeys.html)。具体事务、触发和清理行为仍须由本项目使用的 SQLite 构建实际验证。

## 10 桥接资源停止与来源隔离（C21）

读取服务的资源停止为锁存状态。现有后台观察发现该状态后，仅同步当前来源和清理代次的账户／目录可用性：账户有旧成功记录时标为过期，无有效记录时暂不可用；目录标为不可用，并且只保留同绑定的旧成功时间和数量。迟到响应、其他来源或旧代次不能恢复这些事实。同步不发起RPC、不更新成功采集时间、不自动重启服务；实际传播延迟仍需原生观察，后台检查间隔不冒充实测延迟。

启动时从继承环境中移除明确的九项键（不区分大小写）：`CODEX_HOME`、`CODEX_ACCESS_TOKEN`、`CODEX_API_KEY`、`CODEX_APP_TOOLS_PIPE_PATH`、`CODEX_INTERNAL_ORIGINATOR_OVERRIDE`、`CODEX_THREAD_ID`、`CODEX_SESSION_ID`、`CODEX_TOOL_CALL_ID`、`CODEX_TASK_WORKSPACE_VERIFYING_IDENTITY`，随后应用所选来源的`CODEX_HOME`与显式配置。保留其他正常运行环境。该清单不证明所有认证方式均已隔离，不改变96／128MiB保护、手动重试或共同退避规则，也不构成资源预警原因或真实账户恢复证明。

## 11 桌面活动与应用基础协议（C23）

`idlePlayEnabled`、`workAppLinkEnabled`均由Core持久化，默认true，非布尔补丁整次拒绝。桌面上下文与`PetPulse`、用量、账户和回合事实独立，不写回账本。既有200ms维护周期负责观察；连续观察120秒无输入后原地玩耍2400ms，两次之间留18000ms间隔。初次采样和暂停恢复都重新建立观察基线，不推定进程启动前已空闲；输入变化、时钟回退、菜单、拖动、选择器、隐藏、锁屏、免打扰或减少动画均取消本轮动作，恢复不补播。系统通知状态只在明确允许时开放自动玩耍，失败或不宜打扰保持安静，不承诺覆盖所有全屏程序。

## 12 来源写入与 CSV 保存补充（C23 后续修复）

本节约束 C23 之后主开发源码的后续修复，不存在于 C23 封存源码、App 或 NSIS 包中；不得将本节的实现或测试归入 C23 候选验收。

来源选择须先成功持久化再发布内存绑定；登记来源、采集通道和能力登记在同一事务提交。路径与 enabled 的组合更新也须同一事务完成，任一写入失败均保留原持久配置和内存绑定，不留下部分登记或部分启停结果。
