# Token 喵 0.1.0 数据来源与统计口径

编写日期：2026-10-15。本文说明当前候选实现的含义与边界；来源能力和已观测范围以应用内逐源健康为准。功能实现不等于完整验收，发布状态见[候选发布说明](候选发布说明与已知限制.md)。

## 数据从哪里来

| 数据 | 当前来源与粒度 | 不代表什么 |
| --- | --- | --- |
| 本机 token 账本 | 已登记 Codex 来源中的普通 JSONL；以有证据的单响应身份记录。支持当前目录与 `archived_sessions` 等归档移动。 | 不代表全部设备、全部账户活动或官方账单。 |
| 回合、工具与代理关系 | Codex 明确记录的事件和元数据；缺少关联不猜测。 | 工具退出码不等于回合结果或业务验收结果。 |
| 账户额度与每日用量 | 自有只读 Codex 桥接读取主来源账户快照及可用的每日桶。 | 不属于本机响应账本，不与本机总量相加。 |
| 目录与聊天入口 | 只读会话目录元数据、来源身份及适配器校验后的会话目标。 | 不通过加载正文补齐；目录完整不等于日志覆盖完整。 |
| 桌宠状态与关心语 | 上述明确事实、全局活动观察及本地规则、预设短句。 | 不调用模型，不推断用户健康或工作时长。 |

当前仅注册 Codex 适配器。本机字段依据包含 Codex 0.147.0 探测及固定样本；日志格式不是永久稳定的公共计量协议。其他客户端、未知版本、缺字段或未知语义会降低能力或报告问题，不按同名模型认定已覆盖。Claude Code、Gemini CLI 尚未接入。

默认读取 `CODEX_HOME`，否则读取当前用户目录下 `.codex`。来源登记、启停、迁移及主账户来源选择由本应用自己的设置保存，不修改 Codex 源配置。

## 有效、缺失与可信子集

指标区分有效、未提供、语义未知和异常。有效的 `0` 保留；“—”“未提供”“尚未记录”不能替换成零。没有有效计量子集时，总 token 可以为空，即使已记录了响应身份。

“已记录响应数”是已保存的有效业务身份数量，可能包含计量缺失或有争议的响应；“进入可信总量的响应数”是其中有有效计量且没有未解决重复疑点的子集。被排除响应另列，不能用主卡片的身份数量反推出平均用量或成功率。

同一来源与业务身份出现不同计量载荷时，保留冲突依据，将整个争议响应排除于可信 token 总量与预算。跨来源相同短 ID 不自动合并，也不自动构成冲突：有明确独立域可分别计量，有证据证明复制才合并，疑似重复而无法确认的范围单列处理。

后补模型、显示名称或账户信息不制造新响应。当前登录账户不回填未知历史归属。

## token 与缓存

| 指标 | 口径 |
| --- | --- |
| 总 token | 有效输入 token + 有效输出 token。 |
| 输入 token | 依来源语义包含相应缓存读取及有效缓存写入细分。 |
| 输出 token | 依来源语义包含推理输出细分。 |
| 缓存读取、缓存写入、推理输出 | 都是细分；不能再次加到总 token 上。 |
| 加权缓存命中率 | 有效且可比较记录的缓存读取总量 ÷ 同一有效子集输入总量；不是逐条百分比的算术平均。分母无有效依据时未提供。 |
| 缓存输入量覆盖率 | 可计算缓存读取口径的输入量 ÷ 可信输入总量；说明命中率覆盖了多少输入。 |
| 普通输入 | 仅在细分包含关系有证据、结果有效时派生；未提供缓存写入不能直接当作零来相减。 |

字段覆盖率的分母可能是输入量，也可能是有效响应数，应按界面对应名称读取；不同覆盖率不能互相替代。字段已接入不代表所有真实来源都提供该字段，非零缓存写入的固定样本验证也不等于本机已出现该场景。

旧格式累计计数仅在具备可核对基线和有效连续段时推导差值。缺基线、累计回退、模型/归属不明等情形保留未知或问题；不通过从零相减制造用量。界面将旧格式推导片段与 token 作为受限估算单列，**不与可信响应总量、预算或响应明细 CSV 混加**。

## 日期、耗时与筛选

事件时间底层保存 UTC；本机按日聚合、日期筛选和一般显示采用 Asia/Shanghai。选择今日、近 7 天、近 30 天或自定义范围时，应留意所选来源和已覆盖日期。

回合耗时来自明确开始、结束信息；“回合首 token 耗时”是 Codex 记录的回合指标。它不等同网络请求级 TTFT、首可见文字延迟或生成 token/s。缺少起止时间、单位依据或字段时不伪造结果。

项目默认按稳定目录身份区分，同名目录不会仅按 basename 合并。显式项目映射可以将多个 worktree 目录归到同一项目。原目录作为元数据保留；隐私显示不改查询身份。

会话、根任务和代理归属均携带来源域。根任务范围包括根自身和有明确关联的子代理；没有证据时不猜测归属。模型是记录或明确元数据中的模型，提供商无证据时显示未知。

代理类型为主代理、子代理、归属未知。主代理只接受已核对来源版本中的明确用户线程分类；当前正判版本为 Codex 0.147.0，不由普通 CLI/VSCode 来源、缺少父会话或主账户来源推导。目录中的线程创建版本不证明当前 RPC 实现版本；不能独立验证时仍归未知。明确父关系或合法子代理来源可以证明子代理；冲突与自指保留为未知，后到空值不抹掉既有证据。缺祖先或未知终点不制造已知根线程。

同一来源与回合出现多个线程归属时，不按数据库行顺序选择一个。唯一原生用量归属不被较晚的普通元数据时间覆盖；后到证据纠正已有收件箱归属时保留提醒身份、已读及通知历史，不重新发出完成通知。

统计筛选作用于相应账本、回合、工具和收件箱查询；悬浮角色的活动观察以及逐源健康保持全局事实，不因面板筛选而消失。预算独立按其规则范围和周期计量。

## 回合结果、收件箱与预算

明确正常结束才显示正常完成；明确失败、中断分别显示。仅有结束事件而缺少结果时显示“已结束，结果未知”。工具正常退出不证明测试、业务或整个任务成功。

提醒按来源与根回合身份去重。未知结果后来补明确结果时更新同一事实，不能借状态变化当成新完成重复播报。已读状态、角色动画回执与系统通知状态分别管理。

首次历史导入、重启补读、隐藏、锁屏及免打扰期间推进相应提示水位，恢复不补播旧短提示。工作关心语同样只使用新鲜事件及实际活动切换；连续快照断流超过 15 秒或时钟回退后重新建立基线，不宣称旧回合仍在运行。

软预算使用可信本机总 token。日、项目、会话预算按上海当地日；根任务预算累计整个根任务及明确子代理，不在午夜清零。账户官方额度不参与这些预算，阈值不会换算成费用或控制工具执行。

## 账户快照

账户与会话目录通过官方 Codex App Server 的限定读取接口取得。该辅助进程启动时会维护所选 `CODEX_HOME` 下的 Codex 运行数据和临时目录；本机私有导入测试观察到了 SQLite 运行文件。日志采集器共享只读打开 JSONL，宠物不发送登录、配置修改或会话恢复请求。测试后，捕获的 379 份 JSONL 全部字节摘要保持一致。

账户快照标注来源、采集时间、重置时间及可用窗口。每个额度桶和窗口独立展示；空窗口、缺失百分比及未提供重置时间保留未知。百分比不换算为“剩余 token”。

超过约 4 分钟未重读、窗口重置时刻已过去或后端标为过期时，界面保留快照并标记过期。到点后不自动归零，也不自动恢复为新额度；需要真实重读。认证不可用或断网时，历史快照不应冒充新读取。

只有主账户来源启用此读取能力；非主来源未提供独立账户能力时显示未提供。切换主来源后不沿用另一来源的账户快照。

官方账户日趋势显示最近 30 个记录日，保留来源给出的 `startDate`；官方未单独提供时区，不能将其擅自换为本机日口径。缺日不补零，缺失 token 不画成零；该趋势不随本机日期筛选变化，不与本机账本相加。

## 健康与覆盖范围

逐源“最近检查”表示尝试检查的时间，“最后成功检查”才是该来源无错误检查水位；最后事件与已观测日期范围是另一个维度。来源能力的支持声明、配置启用、当前运行态分别展示；一个来源可用不保证所有字段都可用。

来源健康不受面板日期、模型筛选裁剪。不支持文件数量在未检查来源存在时可能未提供，不能把已知部分当成完整零值。问题列表为空不代表全部历史、全部格式、全部来源已覆盖。

当前支持普通 JSONL 和归档移动，尚不解压所有历史压缩格式；不支持的压缩/来源文件进入健康记录。部分行、损坏内容、未知语义、文件替换或读取失败会保留游标与问题边界，不将缺口当作无活动。

会话目录桥接虽可分页读取，本地单次合并安全上限仍为 **10,000 条**。超过上限会在写入前明确拒绝并保留旧目录快照及旧成功水位，不声明已完整覆盖更大目录。

## 隐私、保存与 CSV

宠物账本保存必要的来源/会话/回合/响应身份、项目映射及目录元数据、模型与计数、时间、工具摘要、健康和提醒。对话正文、命令参数、工具输出、凭据和完整账户响应不进入宠物数据库。隐私模式隐藏显示内容，不删除这些必要元数据，也不是不可关联的匿名化方案。

CSV 使用当前账本筛选导出可信响应，字段包括 `source_id`、`thread_id`、`response_id`、`event_time`、`project`、`requested_model`、输入/输出/总量、缓存读取/写入、推理输出、计量语义版本和质量。未提供的数值留空；旧格式估算、冲突排除项、账户快照和工具内容不混入响应 CSV。

隐私模式下 `project` 使用替代标识，但来源/线程/响应 ID、模型和时间仍保留。因此导出不是完全匿名文件；分享前应按实际用途检查。CSV 具有单个 UTF-8 BOM，使用引号转义，处理换行及公式起始字符；取消原生保存对话框不会被当作导出成功。

清理和保留策略只作用于宠物自己的数据，并保留清理水位以免马上回灌，不修改 Codex 源日志。清理账户/目录缓存后拒绝旧在途响应重新发布；随后真实新读取仍可产生新快照。恢复被清理历史需要显式补导。
