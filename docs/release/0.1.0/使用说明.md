## 开始使用

Token 喵只读采集本机 Codex 的用量与状态，提供桌面伙伴“小柚”和统计主面板。本应用不发送模型推理请求，不控制 Codex 任务，不调用登录或配置写入操作。账户快照读取仍依赖本机 Codex 的可用性、认证及网络状态。读取账户与目录时启动的官方 Codex 服务可能自行维护本地状态库；本应用不直接读写其凭据或状态数据库，源日志仍只读。

默认来源尊重 `CODEX_HOME`；未设置时使用当前用户目录下的 `.codex`。启动后先查看“来源与数据健康”，确认来源已启用、运行态可用，并检查覆盖日期和问题记录。没有记录或来源未提供指标时，界面显示“—”“未提供”或“尚未记录”，不应据此认定用量为零。

浏览器中的“演示预览”使用样本数据，不能读取账户或代表本机真实统计。真实采集请使用桌面候选程序；文件名和最终校验值由交付记录确定。

## 与小柚互动

小柚是本项目设计、AI辅助生成的日式Q版猫娘，保留猫耳、猫尾，使用人类手脚。当前v12内置16个片段：待机、活动、提醒、正常完成、睡眠，开心、眨眼、贴心、害羞、鞠躬、伸懒腰、抱尾巴，以及左右侧走和两个方向的掉头。侧走与掉头只在原地预览，不启用自主移动；静态模式复用待机姿态。可爱动作不代表任务成功。

| 操作 | 作用 |

## 工作联动与关心语

“偏好设置 → 桌面伙伴 → 工作联动与关心语”提供以下选项。

| 设置 | 默认及含义 |
| --- | --- |
| 工作联动关心语 | 默认开启；关闭后保留原有摸摸姿态及事实角标。 |
| 关心语气 | 默认“两种风格交替”，按实际显示的每句在温柔克制与轻轻卖萌之间轮换；也可单选一种。 |
| 持续活动关心间隔 | 默认 25 分钟，可选 45 或 60 分钟。依据持续收到的进行中回合快照，不是对用户本人工作时长的测量。 |

短句全部内置，不调用模型，不插入项目名、目录、会话标题或正文。工作开始、明确正常完成、失败、中断、结果未知和真实本地软预算使用不同回应；没有明确成功证据时不会庆祝成功。持续活动关心只说“回合仍在进行”，不会作健康诊断。摸摸也可收到一句本地回应。

同一批短提示较多时，优先显示重要提醒，其余记录仍可在收件箱查看。首次读取时显示“正在读取本地活动…”，已有观察失效时显示“活动数据待更新”；隐藏恢复、切换来源或跨日后等待当前状态，不补播旧关心语。

事实角标和实际任务状态始终独立保留。关心语不会自动打开窗口、停止任务、审批、切换模型或处理预算超限。

## 静音、免打扰与隐私

在“偏好设置 → 提醒与隐私”调整：

- **静音**默认开启。关心语始终是文字，不新增声音或系统通知；静音与关心语开关分别控制。
- **免打扰**默认关闭，可手动开启或设置时段。时段按 Asia/Shanghai 计算，起止相同表示不启用定时段。期间继续记账、保留收件箱，恢复后不补播短提示或关心语。
- **隐私模式**隐藏项目名称、会话标题和目录等显示内容。它不删除账本，也不等于完全匿名；导出仍保留必要的业务标识，详见[数据说明](数据来源与统计口径.md)。

“桌面伙伴 → 减少动画”或系统减少动画偏好会使用静态姿态，仍可显示事实文字和关心语。免打扰使用静态睡眠姿态；隐藏、锁屏或减少动画优先使用静态待机姿态。

默认不开机自启。可在“桌面伙伴”开启或撤销“登录 Windows 时启动”；实际登录启动效果仍属于安装与系统验收范围。

## 来源与账户

在“来源与数据健康”点击“登记 Codex 来源”，通过目录选择器选择来源。每个新登记来源有独立身份；迁移已有来源时使用其“更改目录”，保持同一身份。不要用“新增来源”代替目录迁移来重复登记同一批日志。

来源可以启停。展开“查看此来源的采集通道与能力”可分别看到支持声明、运行态、最后检查、最后成功检查、事件范围和未覆盖文件；“最近检查”不等于成功。缺失值保持未知。

“设为主账户来源”仅对已启用的 Codex 来源开放。账户快照只属于主账户来源；其他来源未启用独立账户读取时显示未提供，不借用主来源额度。账户窗口会展示采集时间和重置时间；显示过期时等待真实重读，重置时刻到达不会自动归零或宣称额度恢复。

账户或会话目录读取失败后会共同退避，目录刷新不会另行反复启动桥接。本次运行中若触发资源保护，自动尝试会暂停，清理账本或切换来源不会解除保护。可先查看“来源与数据健康”的目录读取状态和错误提示，稍后在“用量概览 → 账户额度”点击右上角刷新按钮，明确发起一次手动重试。重试仍可能失败，也不会由本应用发起登录或配置写入操作。

“暂不可用”不等于未登录。读取失败时可能保留旧额度，请结合采集时间查看，不能将旧值当作刚刷新成功；没有快照时也不按零额度处理。仅官方日趋势暂不支持或被服务拒绝时，可以保留本次有效额度，日趋势显示未提供；连接断开、超时或资源保护不会被当作成功读取。

C19 本轮实机观察中的目录读取触发资源保护，数量和最近成功时间未提供，未额外发起重试或账户操作。本地用量持续更新不代表账户目录或聊天定位可用；需要时按上面的数据健康提示和手动刷新入口处理，不能把缺失值当作 0。

Claude Code 和 Gemini CLI 当前没有可用接入入口。

## 软预算

在“偏好设置 → 软预算”添加正整数总 token 阈值，可选本地日、项目、会话或“根任务累计 · 含明确关联子代理”。预算使用可信本机响应账本，不使用账户剩余额度。

根任务预算累计整个任务，不在午夜重置；其他预算按上海当地日重新计量。会话和根任务带来源域；无法明确归属时保持未知。预算不随概览日期筛选改写周期。

同一规则、周期和档位仅提醒一次；保存规则不会回弹历史提示。达到阈值只提醒，不停止任务、不改变工具执行，也不产生费用估算。

## 历史、保留与清理

当前C39仍使用本地账本版本6，闭库限定审计已确认该schema；版本6由历史C19引入，C20R1等后续候选沿用。升级前在数据目录保存`ledger-before-v6-*.sqlite3`一致备份。首次升级需要额外磁盘空间和迁移时间；失败会保留原账本与备份。旧候选可能无法打开版本6，请使用对应候选及配套说明，不直接用旧程序覆盖新账本。C18的版本5、C17的版本4与对应备份记录保留于历史候选说明；当前自绘安装器的实际升级仍未验收。

版本 6 为五张表增加清理时间索引，历史暂停、取消、保留水位及补导操作保持下述方式。[Core 限定回归](../../acceptance/c19-retention-v6-core-composite-2026-10-16.json)由 79 个不同用例、80 次执行组成，保留原失败后只补跑修正项；不代表实际用户库升级、桌面导入性能或加速已验收。新安装包已构建，尚未执行安装。

首次默认安排最近 30 天历史采集，实时新增优先。“来源与数据健康 → 覆盖范围与历史”可以选择起始日期并“补导历史”。界面区分补导中、已暂停、已取消、空闲，以及尚未提供状态。

独立[全规模 Core 对账](../../acceptance/c19-c18-full379-core-reconciliation-2026-10-16.json)已在冻结 C18 库上读取 379 份、约 4.275 GB 日志，历史与实时游标均追平，并核对默认近 30 天的 104,188 个原生响应及六项用量字段。这是后台 Core 的限定证据，不代表当前桌面程序的导入性能、所有旧格式和事件语义都已验收，也不改变先前 C15 导入截止未完成的结果。实际使用时仍以各来源的覆盖范围、待导入文件和问题记录为准，不把“刚刷新”当作历史已经收齐。

- “暂停补导”后可“恢复补导”。
- “取消补导”会跨重启保留取消状态；需要重新选择日期并点击“补导历史”，不能用恢复按钮重启已取消任务。
- 暂停或取消历史不会停止新文件或已有文件新尾部的实时采集，也不会删除已记录事实。

“偏好设置 → 数据与账户”默认保留本地账本 90 天。“清理超期数据”应用所选保留策略；“清理本地账本”需确认，将清理宠物保存的用量、回合、工具、提醒及账户快照。两者均不删除或修改 Codex 源日志。清理水位避免下次扫描立即回灌；需要恢复时显式补导历史。

## 导出与排查

C20R1在 `desktop-metrics.json → accountBridgeResource` 新增排查记录，保留单条有界资源事件或null，不包含账户响应、对话或工具参数。阶段仅是最近选择阶段，不能证明方法已发送或预警原因；null也不表示账户／目录刚读取成功。96 MiB预警、128 MiB硬限、共享熔断与上文手动重试入口保持不变，清缓存或切换来源不会解除保护。[私有空源／null账户探测](../../acceptance/c20-private-bridge-probes-2026-10-16.json)不替代真实来源成功，本次不声明原目录故障已修复。C20R1实机仍记录idle／启动后3940 ms、121.8945 MiB超过96 MiB预警，账户警告与stale可见；早期connected／count0只代表预警前的空子集。`ownerCleanupElapsedMs=119971`为启动至后来首次owner清理动作时点，不能解读为清理耗时或120秒才终止进程；最近选择阶段也不证明内存根因。

在主面板按需要设置筛选后点击 CSV 导出，选择保存位置；正常取消返回空值且不显示成功提示。导出包含可信响应明细，提供 UTF-8 BOM、引号、换行及公式起始字符防护。旧格式估算、账户日趋势和工具内容不混入该 CSV。

C18 已通过原生保存对话框明确保存两份文件，分别核对近 7 天 2 行／2200 token 和今日 1 行／1000 token，均为单 UTF-8 BOM、14 列；双击导出时观察到一个保存窗口。一次实际坐标取消后没有生成预定文件，但先前一次 UIA“取消”意图却发生保存，原因尚未确定且原文件保留。请在实际对话框确认操作与保存位置；这轮证据不代表全部取消竞态、隐私／公式防护或 Excel 打开已实机验收。

隐私模式下项目字段使用替代标识，但来源、会话、响应身份、模型和时间仍保留。分享前按用途检查文件；具体字段见[数据来源与统计口径](数据来源与统计口径.md)。
